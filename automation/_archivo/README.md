# Archivo de automation/

Código fuera de uso, conservado por referencia. Nada aquí se ejecuta en la operación normal.

- `whatsapp_webhook_server.py`: bot de prueba que contestaba lo mismo que recibía, a cualquier número, sin firma. Reemplazado por `kapso_whatsapp_bot.py`.
- `pruebas_manuales/`: scripts sueltos para probar modelos y latencia de Gemini. No son tests automáticos; las pruebas reales están en `automation/tests/`.
